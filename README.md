# 💳 Credit Card Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Credit Card Analytics Dashboard** built using **Power BI** to analyze customer behavior, transaction trends, revenue generation, risk analysis, activation performance, and geographic insights.

The dashboard helps financial institutions and business analysts monitor:

* Customer spending patterns
* Revenue & profitability
* Credit risk & delinquency
* Customer engagement
* Geographic and demographic intelligence

The report is designed with multiple interactive pages, KPI cards, slicers, charts, and drill-down analysis to provide actionable business insights.

---

# 🚀 Features

## ✅ Interactive Dashboard Pages

The dashboard contains multiple analytical sections:

### 1️⃣ CC Transactions

* Weekly transaction trends
* Expense category analysis
* Transaction volume monitoring
* Card-wise transaction insights

### 2️⃣ CC Customers

* Customer segmentation
* Demographic analysis
* Customer behavior patterns
* Spending analysis by customer groups

### 3️⃣ Risk & Credit Health

* Delinquency analysis
* Credit utilization tracking
* Risk segmentation
* Quarterly delinquency trends

### 4️⃣ Revenue & Profitability

* Revenue source analysis
* Profitability tracking
* Revenue contribution by card category
* Expense category profitability

### 5️⃣ Geographic Intelligence

* State-wise customer analysis
* Geographic revenue distribution
* Demographic insights
* Satisfaction vs revenue analysis

### 6️⃣ Activation & Engagement

* Card activation monitoring
* Customer engagement analysis
* Revenue per activation
* Transaction behavior analysis
